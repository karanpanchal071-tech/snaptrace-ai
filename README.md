# SnapTrace AI

Phone-first AI debugging agent for Android incidents.

## Phase 1 prototype
Interactive ideation prototype for the iQOO Hackathon Developer Tools track.

**Demo:** Trigger ANR → capture → Office Kit transfer → AI diagnosis → evidence → suggested fix → verification.

> Prototype performance values are simulated for Phase 1 and are not claims about actual iQOO hardware measurements.

## Planned build
BugLab Android app + SnapTrace SDK → incident bundle → Office Kit → laptop AI debugging agent → timeline/evidence/root cause/fix.
